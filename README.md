#Finance models in Python

Quantitative finance models built in Python as part of self-directed learning 
alongside Bcom Major in Econ & Finance at UWA

## Projects
- **Monte Carlo Simulation** — RKLB stock price path simulation using Geometric 
  Brownian Motion, interactive fan chart, 3D price surface, VaR/CVaR risk metrics<img width="880" height="566" alt="Screenshot 2026-05-12 142801" src="https://github.com/user-attachments/assets/9b7fb7b7-23eb-49f0-aaa0-537c19a87c5d" />


- **Black-Scholes-Merton Model** — RKLB options pricer with full Greeks 
  calculation (delta, gamma, theta, vega, rho), interactive slider dashboard, 
  and 3D volatility surface across strikes and expiries
- **Pairs Trading Algorithm** — EURGBP/EURUSD FX pairs strategy using 
  Engle-Granger cointegration testing, rolling z-score signals, and 
  full P&L backtest with Sharpe ratio and drawdown analysis

## Tools
Python · Jupyter · NumPy · Pandas · Plotly · yfinance
